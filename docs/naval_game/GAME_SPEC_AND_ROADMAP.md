# 3D海戦アクション 仮仕様書・開発計画

作成日: 2026-07-06  
基準日程: 8月31日に戦闘試作、9月30日に無料公開候補版  
仮称: `Project Naval`（公開名ではない）

## 1. 企画の芯

自分で選んだ兵装を積む艦を直接操り、多数の敵艦を豪快に撃沈して、戦果でさらに強い艦へ更新する短編3D海戦アクション。

参考にする要素は、ミッション前の準備、兵装ごとの戦い方、直接操艦、大量撃破、巨大ボス、戦果による成長という抽象的なゲームループに限定する。固有名詞、物語、UI、数値、ステージ、超兵器デザイン、音・画像は独自制作する。

## 2. 想定条件

- Windows向け、キーボード＋マウス／XInput対応
- 一人用・オフライン
- 1プレイ5～12分、全体45～90分程度の小品
- 開発者一人を前提とし、既存の2D・3D制作と両立
- 8月末は完成品ではなく、面白さと技術の成立判定版
- 9月末の第一候補は無料版。有料化は9月15日の品質判定で決める

## 3. コアループ

```text
母港でミッション選択
  → 艦と兵装を選択
  → 出撃して目標を達成
  → 資金／パーツを獲得
  → 火力・速力・耐久の選択を更新
  → より強い敵と巨大ボスへ挑戦
```

楽しさの優先順位は「撃った手応え」「艦を操る重さ」「装備を変えた効果」「次の強化が欲しくなること」とする。

## 4. 戦闘仕様（8月末必須）

### プレイヤー艦

- 水平面を移動し、スロットル段階と舵で操作する。
- 速度は即座に変わらず、前進速度が高いほど一定範囲まで旋回が効く。
- HPが0で撃沈。部位別耐久や浸水は入れない。
- カメラは艦尾追従。マウス／右スティックで周囲確認できる。
- 照準は画面中央または水面上の狙点。近い敵への任意ロックを補助として用意する。

### 兵装

| 系統 | 役割 | 8月末 | 9月末候補 |
|---|---|---:|---:|
| 主砲 | 中～遠距離、放物線、斉射の爽快感 | 必須 | 口径違いを3種 |
| 魚雷 | 近～中距離、高威力、長い再装填 | 必須 | 速度／本数違いを2種 |
| 機銃／対空砲 | 近距離の高速連射 | 任意 | 航空機を入れる場合のみ |
| ミサイル | ロック式で扱いやすい高性能兵器 | なし | ボス報酬として1種 |

主砲は複数砲塔を同時斉射できる。ただし砲塔ごとの精密な装填や砲身単位損傷は扱わない。射撃時は砲煙、反動、音、弾道Trail、着弾爆発または水柱を組み合わせる。

### 敵

- 小型艇: 接近し連射。低耐久で多数撃破用。
- 砲撃艦: 距離を保ち主砲射撃。標準敵。
- 雷撃艦: 横方向へ回り込み魚雷を発射。
- ボス艦: 大型、高耐久、HPに応じて行動を2段階変更。

8月末は小型艇・砲撃艦・ボスの3種で成立させ、雷撃艦は余裕がある場合のみ追加する。

### ダメージとフィードバック

- 直撃ダメージ＋爆風の簡易範囲ダメージ。
- 敵HP、プレイヤーHP、被弾方向、ロック対象、装填状況をHUD表示。
- 命中時に火花／煙、撃沈時に段階的爆発と短い沈下演出。
- 水面着弾はダメージなしで水柱を出し、外したことが即座に分かる。

## 5. ミッション仕様

### 8月末の縦切り1ミッション

1. 出撃地点から目標海域へ接近
2. 小型艇の第一波
3. 砲撃艦を含む第二波
4. ボス艦出現
5. ボス撃沈で結果画面

クリア時間は8～12分。リトライ可能。報酬は仮表示でもよい。

### 9月末の公開候補

| # | 内容 | 新しく学ばせること |
|---:|---|---|
| 1 | 射撃訓練＋小型艇掃討 | 操艦、主砲、ロック |
| 2 | 敵艦隊撃破 | 射程管理、魚雷 |
| 3 | 味方輸送艦の簡易防衛 | 優先目標の判断 |
| 4 | 濃霧または夜戦風の決戦 | 索敵距離の変化 |
| 5 | 巨大ボス艦 | 装備更新の成果確認 |

護衛AIを作り込まず、ミッション3の味方艦は定位置または単純航路とする。ミッション4の特殊環境が重ければ通常海域の高難度戦へ置き換える。

## 6. 艦装・成長仕様

完全自由配置ではなく、艦体に用意されたスロットへ装備する方式とする。

- 艦体スロット: 主砲2、特殊兵装1、補助装備2
- 艦体候補: 軽量艦、標準艦、重装艦の最大3種
- 主砲候補: 軽砲、中砲、重砲
- 特殊兵装: 魚雷、公開候補版ではミサイルも可
- 補助装備: 装甲、機関、装填、照準の4系統

装備変更で、火力・射程・装填・速力・旋回・耐久・重量が変化する。重量は上限だけを持ち、重心や浮力計算はしない。

報酬はステージ初回報酬＋戦果評価。ランダムドロップは初版では使わず、欲しい装備への道筋を明確にする。

## 7. データ方針

艦、兵装、敵、ミッション、報酬をJSON化する。コードに個別ステージの数値を埋め込まない。

最低限のデータID例:

```text
ship.player.standard
weapon.gun.light
weapon.gun.heavy
weapon.torpedo.basic
enemy.gunboat
enemy.cruiser
enemy.boss.prototype
mission.01.training
```

セーブにはデータ形式バージョン、所持資金、解放装備、装備中ID、クリア状況、設定だけを保存する。保存失敗で進行不能にならないよう、初期値へ復帰できる構造にする。

## 8. 画面構成

- Naval Title: 開始、続き、設定、終了
- Port: ミッション、艦装、出撃
- Loadout: 艦体・兵装・補助装備、能力比較
- Briefing: 目標、敵傾向、報酬
- Battle: HUD、ポーズ
- Result: 評価、資金、解放

8月末はTitleからBattleへ直接入りResultへ戻る簡略フローでよい。Port／Loadoutは戦闘が面白いと判定した後に実装する。

## 9. 開発工程

### フェーズA: 技術スパイク（7月6日～7月19日）

- Naval専用シーンとフォルダを追加
- 仮モデルで海面、艦尾カメラ、操艦
- 1基の旋回砲塔、重力付き砲弾、着水判定
- 静止標的への命中、爆発、水柱

終了条件: 1分間操作して、狙って撃ち、命中／外れが気持ちよく判別できる。

### フェーズB: 戦闘成立（7月20日～8月9日）

- 複数砲塔斉射、装填、魚雷
- 敵艦の操船・射撃AI
- HP、撃沈、HUD、ロック補助
- 弾数・敵数を増やした性能確認

終了条件: プレイヤー対3～5隻の戦闘が勝敗まで成立する。

### フェーズC: 縦切り（8月10日～8月23日）

- 1ミッションの増援・ボス・結果
- ボス2段階行動
- 仮音声とエフェクトを統合
- キーボード／ゲームパッドで通しプレイ

終了条件: 起動から結果までクラッシュせず8～12分遊べる。

### フェーズD: 8月末判定版（8月24日～8月31日）

- 不具合修正、操作説明、リトライ
- Releaseビルドと別PC相当の配布フォルダ確認
- 面白さ、性能、残作業を評価

8月31日の継続条件:

- 砲撃と撃沈に手応えがある
- 30fps未満へ継続的に落ちない目標（最終目標は60fps）
- 重大クラッシュ／進行不能がない
- 9月に追加する内容を既存機能の磨き込み＋データ追加へ限定できる

### フェーズE: 小品化（9月1日～9月14日）

- Port、Loadout、報酬、セーブ
- 艦体／装備バリエーション
- ミッションを最大5個まで追加
- 独自素材への置換、設定画面

### フェーズF: 公開準備（9月15日～9月30日）

- 9月15日に無料／有料／延期を判定
- バランス、チュートリアル、入力、音量、解像度
- Releaseで繰り返し通しテスト
- 権利確認、README、クレジット、スクリーンショット、配布パッケージ

## 14. 画面参考から抽出したバトルUI方針

2026-07-07に、PSP版系の戦闘画面参考画像を確認した。画像そのものはネット由来のため、素材としてリポジトリには含めない。参考にするのは画面要素、情報密度、レイアウト思想に限定する。

### 抽出した画面要素

- 画面中央に大きめの円形照準／射撃補助サークルがある。
- 艦は画面下寄りに表示され、カメラは艦尾斜め上から広い海域を見せる。
- 敵や味方の上に、遠距離でも分かるマーカー／ラベル／HPバーが出る。
- 左下にミニマップ／レーダーがあり、自艦、敵、味方、目標方向を表示する。
- 右側に兵装スロット一覧が縦に並び、弾数や装填状況を表示する。
- 右上にロック対象または目標情報の小窓がある。
- 左側にプレイヤー名、チーム、HP、スコアなどのステータス表示がある。
- 画面下部に速度、方位、兵装名、弾数、メッセージが表示される。
- 水平線、島影、遠方敵、弾道、ミサイル／砲弾の軌跡で「広い戦場」を演出している。

### 独自実装へ落とし込む優先順位

1. 中央の円形照準と着弾予測補助
2. 左下レーダー
3. 右側の兵装リストと装填ゲージ
4. 敵艦上のHPバー／距離表示／ロックマーカー
5. 右上のロック対象情報
6. 画面下部の速度・方位・砲弾数表示

### 初期プロトタイプでの簡略版

最初から完全なUIを作らず、まずは以下の簡略版で戦闘の見通しを良くする。

- 中央に薄い円形照準、またはImGui/2Dスプライトの簡易レティクル。
- 左下に自艦中心の簡易レーダー。敵は赤点、プレイヤーは白または青点。
- 右下に主砲のリロードと現在兵装名を表示。
- 敵の上に小さなHPバーまたは色付きマーカー。

この方針により、現在のプロトタイプを「ただ海上で物体が動く画面」から、「艦隊戦をしている画面」へ寄せる。

## 15. 30秒参考動画からの追加観察

2026-07-07に、約36秒の参考動画をローカルJPGフレームへ切り出して確認した。切り出し画像は作業用一時フォルダにのみ置き、リポジトリには含めない。

### 確認できた挙動

- 自艦は画面下寄りに大きく映り、艦尾寄りの三人称カメラで海面と水平線を広く見せる。
- 中央には大きな円形レティクルがあり、通常時も照準補助が常に画面の主役になる。
- 精密射撃モードでは、敵を中央へ捉える大きめの照準円が強調される。
- 実機直撮り確認では、照準レティクルが画面中央の一定範囲内を先に動き、範囲端に近づいた時にカメラ／視線が追従する挙動が確認できた。
- 船体の旋回だけではカメラ方位は変わらず、カメラはレティクル操作または照準操作でのみ動く。
- 左下レーダー、右側兵装リスト、右上ミッション／目標表示が同時に出ており、HUDの情報密度は高い。
- 速度は「押している間だけ進む」より、艦の出力を決めて進ませるスロットル操作に近く、確認範囲では `3, 2, 1, 0, -1` の段階表示。
- 砲弾系兵装はレティクル方向へ撃つが、各砲塔には射界がある。船首方向を狙うと後部砲塔は撃てず、横方向を狙うと前部・後部の両方が射界に入りやすい。
- どの砲塔も射界に入らない、または射撃解がない場合は、レティクルが赤くなり中央が照準マークではなく×表示になる。
- 通常射撃では敵への自動ロック補正を行わず、プレイヤーが動かしたレティクル方向へ撃つ。ロック／追尾補助は精密射撃モード側の表現として扱う。
- 通常射撃の納得感を優先し、レティクルからカメラ視線レイを作る。レイが海面に当たる場合はその海面位置へ着弾する放物線を計算し、空へ向けた場合は射界内なら上向きの砲弾として飛ばす。
- 自艦近くの海面も狙えるよう、レティクル海面狙点が近距離の場合は砲弾の水平速度を落とし、固定高速弾による飛び越しを避ける。
- 精密射撃は、レティクル付近かつ精密射撃射程内の敵がいる時に入る専用モードとする。モード中はレティクルを画面中央に固定し、選択中の敵へカメラと弾道補助を寄せる。左右入力で射程内の別敵へ対象を切り替え、再入力で終了する。
- 精密射撃中の固定レティクルは、敵艦の水面位置ではなく艦体中央付近へ合うよう、カメラYawだけでなくPitchも選択中ターゲットへ追従させる。
- 精密射撃中に自艦が横移動してもレティクル中心から敵が左右に逃げないよう、通常カメラより強い追従速度でターゲット方向へ補正する。
- 砲撃時は水柱、煙、弾道、航跡が多く、海戦らしさの大部分をエフェクトが作っている。

### プロトタイプへの反映順

1. 段階式スロットル、停止操作、艦らしい旋回慣性
2. 中央レティクル、精密射撃モード、ロック距離表示
3. レティクル境界スクロール方式のカメラ操作
4. 砲塔ごとの射界判定と、射撃可能／不可のレティクル色変更
5. 左下レーダー、右側兵装リスト、上右ミッション表示
6. 水柱、爆発、煙、航跡の簡易エフェクト
7. 敵艦ラベル、距離、HPバー

2026-07-07時点のプロトタイプでは、まず1〜5をImGuiベースで実装し、描画パイプラインや素材追加に依存しない形でゲーム性を確認する。

## 16. 2026-07-08時点の短期方針

参考動画と実機直撮り確認により、次の短期順で進める。

1. PSP版戦闘画面に近い敵艦ラベル、距離、HPバー、精密ロック強調を先に整える。
2. その直後に海シェーダーへ着手し、水平線、海面色、波の雰囲気を強める。
3. 兵装切り替え、敵AI、被弾／撃沈演出などのゲーム性を拡張する。
4. その後、艦装・ミッション進行・スコアなどの長期要素へ進める。

2026-07-08の実装では、まず敵艦上に `ENEMY SHIP` 名、距離、HPバー、ロック対象強調をImGui HUDとして追加した。これは仮UIだが、PSP版の「遠距離でも敵の状態が読み取れる」画面密度を優先したもの。

海シェーダーは、PSP版の明るく読みやすい青い海を基準にしつつ、現在のシェーダーで表現しやすい範囲として、ワールド座標ベースの波模様、白波、遠距離の深い青、斜め視線の反射感を加える。初期実装では専用PSOを増やさず、既存Object3dシェーダー内に水面モードを作り、海オブジェクトだけ特別なMaterial値で分岐させる。将来的には、頂点変位、法線マップ、反射、航跡、砲弾着水波紋を専用パスへ分離する。
