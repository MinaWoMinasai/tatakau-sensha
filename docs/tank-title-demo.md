# タイトル背景の自動プレイ

通常起動は `tank_game.project.json` の `TITLE` から始まります。`run_tank_expedition.ps1 -SkipTitle` は従来どおり遠征の機体選択へ直接進みます。

タイトルは実際の `GameScene` を所有し、20秒ごとに序盤・中盤・終盤・ボスの4場面を繰り返します。背景では通常の敵AI、弾、壁・敵との衝突、ダッシュ、撃破処理を使います。デモの操縦だけを `Player::SetDemoInput` で置き換え、実際のマウス・キー状態や環境変数を書き換えません。

- 序盤：ベーシック、改造なし、通常の単発射撃。
- 中盤：連射・反射・分裂の固定改造。
- 終盤：上記に誘導・ダッシュバーストを追加し、チェックポイント進化を適用。
- ボス：重弾・誘導・オーバードライブ・貫通・ダッシュバーストの5改造。ダッシュ時の誘導強化と爆発の組み合わせを見せます。
- デモのプレイヤーのみ無敵にして、放置中に停止しないようにします。敵へのダメージは実際の射撃・衝突によるものです。
- 部屋クリアを判定した後は既存の報酬・進路選択を自動操作します。20秒ごとの場面変更では固定ビルドと区画の開始状態を復元します。この初期状態の準備は、実プレイによる撃破・報酬・進路の検証カウンターに含めません。
- 近い敵を照準し、射線のある敵を優先します。壁に遮られた場合は小さな固定グリッドの経路で接近します。射程内では定期的に周回方向を変え、近くの敵弾にはダッシュを要求します。

ゲームHUDは描かず、グローバルポストエフェクトで背景にガウスぼかし・減光・彩度低下を適用します。背景に42%の暗幕を重ねて移動する弾や壁と文字のコントラストを安定させ、タイトルの文字と文字の発光はその後に描画します。

Enter / Space / 選択項目クリックで背景の更新をそのフレームから止め、フェード後に新しいシーンを生成します。デモのビルド、無敵、入力上書き、HP、報酬は新規ゲームへ持ち越しません。↑↓でフリープレイ・基本操作チュートリアルにも移動でき、既存の実験モードへのファンクションキーも維持しています。

## 検証

`project/tools/test_title_demo.ps1 -Configuration Release` はデモ4場面を実際に動かし、各場面の画像、フェード中のシミュレーション停止、新規遠征への遷移を検査します。成果物は `project/generated/title_demo/` です。

`validation.json` の `projectileEmissionSamples` はフレーム間のプレイヤー弾数の増加を合計した観測値です。同じフレームに消える弾もあるため、発射イベントの厳密な総数ではありません。撃破・ダッシュ・自動報酬・自動進路の実行回数は別々に記録します。タイトルの決定入力と同じ遷移関数を自動検証から呼び、実キー操作の確認は別途実画面で行います。

各場面の初期ビルドは実際の発射設定から記録します。さらに毎フレーム、場面変更前に強誘導の旋回速度・ダッシュ爆発発生数・実際の壁反射／敵貫通／分裂した子弾の生成数を観測します。通常の部屋移動でも弾の統計はリセットされるため、場面内では最大観測値を保存します。設定が存在するだけでなく、終盤で反射・分裂、ボス戦で敵貫通・強誘導・ダッシュ爆発が発生したことを完了条件にしています。

初回のモデル・シェーダー準備時間を含め、検証の制限時間は300秒です。
