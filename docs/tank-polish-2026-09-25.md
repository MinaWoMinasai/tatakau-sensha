## 起動

```powershell
./project/tools/run_tank_expedition.ps1 -Configuration Release
```

通常起動はタイトルから開始する。`-SkipTitle`は遠征へ直接入る。既存の`-Validate -Wait`はタイトルを経由せず、遠征の自動検証を実行する。

## 操作と調整

- WASD移動、マウス照準、左クリック射撃、Shiftまたは右クリックでダッシュ。
- TABで改造の全一覧を開閉。開いている間は戦闘停止。
- 報酬画面のEで整備とカード選択を切り替える。
- F2で遠征バランスエディターを開閉。戦闘を止めて編集し、Apply後にF2でその場から試遊する。
- Saveは適用してJSON保存、Reloadは保存済みJSONを再適用、Resetは組み込み既定値へ戻す。Resetだけではファイルを書き換えない。
- 一度専用チュートリアルを完了すると、次回はF3でスキップできる。履修状態は`project/resources/configs/expedition_user.json`に保存する。
- F1の性能表示とShift＋F1のページ切り替えは継続。開発用カメラ切り替えはCtrl＋Shift＋D（Development）へ変更した。

バランス保存先は`project/resources/configs/tankExpeditionBalance.json`。ReleaseでもF2を使用できる。`CG2_PERF_DISABLED=1`で診断用ImGui自体を無効にしている場合はF2エディターも非表示になり、JSONは引き続き読み込まれる。

## 成長の設計

| 基礎値 | 変更前の遠征 | 新しい開始値 |
| --- | ---: | ---: |
| 最大HP | 150 | 120 |
| 攻撃力 | 5 | 4 |
| 弾速 | 0.38 | 0.27 |
| 発射間隔（frames、小さいほど速い） | 18 | 20 |
| 移動速度 | 0.29 | 0.23 |

以前は開始機体・主軸の倍率や複数砲口がさらに加わっていた。今回は全系統がレベル1・単砲身の通常弾で出発する。開始時の選択は将来の進化系統と主軸の設計図で、主軸は改造を2つ取得すると起動する。

初回報酬は高速装填（既定で間隔−40%）、重い弾頭（威力＋80%・弾速＋20%）、スラスター（移動＋25%）の3択。中継地点で多砲身やドローンなどへ進化し、反射・分裂・誘導・ダッシュ攻撃の組み合わせを伸ばす。

遠征の迎撃弾は敵1体を貫通し、同じ相手には重複命中しない。分裂砲口は発射時の弾数増加に加え、最初の敵命中または壁衝突で威力55%の子弾2発を出す。子弾は再分裂せず、残り寿命・反射回数・所有者を引き継ぐ。反射カード単体は1回、反射主軸は2回、両方で4回。跳弾機体の進化にも反射回数がある。

重い弾頭＋ダッシュバーストでダッシュ時の範囲爆発、誘導弾＋オーバードライブで発動中の誘導旋回速度が2倍になる。遠征の弾は所有者ごとに生存240発を上限とし、命中時の分裂は衝突判定の走査後に生成する。

最初の部屋は攻撃する敵2体、HPと攻撃頻度を低く設定し、内部障害物なし。その先では既存の狙撃・突進・シューターを混ぜ、遮蔽物と危険な壁を増やす。ボスの弾数・速度・威力・攻撃間隔もエディターから変更できる。数値の最終的な遊びやすさは試遊を通して引き続き調整できる。

## 検証結果

単体・回帰テスト：分岐8経路、進化6系統、初回報酬512シード、JSON保存／失敗時の保持／値の範囲、チュートリアル6手順、実装本体を使った貫通・分裂・反射・弾数上限、既存の迎撃・資源所有権を確認済み。

Release／Developmentの最終ビルド成功。タイトル検証、専用チュートリアル実動検証、5区画通し（Variant 4）成功。通し検証では進化後のバンクショット、整備4ポイントの保存、改造5個、音声9素材の読み込み・再生を確認し、検証エラーは0。Releaseエディターの編集・適用・保存・再読込・初期値復元も画面から操作して確認した。

最終ビルドのログ：`generated/tank-polish-release-verified.log`、`generated/tank-polish-development-verified.log`。戦闘を伴う検証後の変更はリザルトの操作説明とソフトウェアキーボード対応で、再ビルド後にリザルト→タイトル→Enterで新規ゲーム、F2の全操作、TABの開閉を実画面で再確認した。

F2／TAB／タイトルのキーはWindowsの押下イベントを1フレーム保持し、短い入力を取りこぼさない。DirectInputの保持状態との二重判定は避け、ソフトウェアキーボードのスキャンコードなし入力にも対応する。従来の移動・射撃入力は維持している。

実動証跡は `project/generated/title_demo/validation.json` と `project/generated/tank_expedition/tutorial_validation/validation.json`。タイトルの発射観測3108はフレーム間の弾数増加の合計で、厳密な発射イベント数ではない。反射・貫通・分裂は実際の衝突経路のカウンター。チュートリアル検証では被弾による中断だけを抑え、強制ダメージは使わずに射撃で敵を倒している。

5区画通しの証跡は `project/generated/tank_expedition/variant_4/validation.json`。こちらは従来の進行確認用の強制撃破も使うため、難易度の適正さを証明するテストではない。実射撃による成長・衝突はタイトルと専用チュートリアル、弾実装のテストで別途検証している。

再検証用：`project/tools/test_tank_expedition.ps1`、`test_tank_expedition_tutorial.ps1`、`test_tank_projectiles.ps1`、`test_tank_collisions.ps1`、`test_tank_tutorial_runtime.ps1`、`test_title_demo.ps1`。実動テストは描画・戦闘を伴うため同時起動しない。明示的な自動検証フラグがある場合だけ、フォーカスが外れても進行する。
