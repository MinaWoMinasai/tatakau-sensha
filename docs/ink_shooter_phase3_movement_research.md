# Ink Shooter Lab 第3段階：イカ形態と潜伏の分離

調査日：2026-09-12。Splatoon 3 Ver.11.3.0の対戦用スプラシューターを対象とする。今回は **イカの形になること** と **自インクの中へ潜っていること** を分けるため、任天堂の公式説明・更新履歴、Leannyの1130公開JSON、解析者本人の説明を確認した。

本資料は実装前の判断根拠。最終的に実装・測定した項目は第3段階の実装報告を参照する。録画の30fpsからゲームのフレーム値を測定していない。

## 確度の区分

- **A：公式説明で確認**。任天堂が通常操作や修正対象として記載している動作。
- **B：公開データの実値**。1130のJSONに直接存在する値。省略された項目や適用条件を推定で補わない。
- **C：解析者の解釈**。パラメータと操作全体の関係。バージョンや計測の端点に注意する。
- **D：CG2の近似・実装方針**。公開された原作の完全な処理とは呼ばない。

## 自色インクは形態そのものの条件ではない

任天堂は、ボタン操作でヒトとイカを切り替えること、自分の色のインクの中で床・壁を移動できること、潜伏でインクを補給できることを説明している。この説明では、変身と潜伏の効果が分かれている。[Splatoon 3公式製品ページ](https://www.nintendo.com/jp/switch/av5ja/index.html)

さらに、公式更新履歴には次の修正が明示されている。

| 記載された修正の要旨 | 確認できる通常の動作 | CG2で直すべき点 |
| --- | --- | --- |
| 空中でイカ形態へ変化すると、インク飛散の演出が出ることがある問題 | 空中でもイカ形態へ変化できる | 空中になっただけで人型へ戻さない。空中変身を床への塗りイベントにしない |
| 自分の色でない場所へ、高所からイカ形態で着地すると床が塗れることがある問題 | 自色でない地面へイカ形態で着地できる | 乾いた地面への着地でも形態を維持する。着地したことだけで床を塗らない |

前者は [任天堂のSplatoon 3更新履歴](https://www.nintendo.com/en-gb/Support/Nintendo-Switch/Game-Updates/Splatoon-3-Update-History-2358763.html)、後者は [任天堂の更新案内](https://www.nintendo.com/en-za/Support/Nintendo-Switch/Game-Updates/How-to-Update-Splatoon-3-2266003.html) で原文を直接取得して確認した。これは「乾いた地面を高速で泳げる」という意味ではない。形態を維持する条件と、高速移動できる条件を分ける根拠である。

タンクの残量は射撃可否に使い、変身入力の受付条件にしない。自インクへ潜って空のタンクを補給する基本ループを成立させるための条件である。変身コストや残量下限を示す公開値は今回確認できなかったため、CG2でも新たな消費・残量制限を設けない。

## 第2段階コードで確認した問題

`Simulation::MovePlayer` は `Shift && !射撃 && 接地 && 自インク && 射撃後隙経過` をすべて満たした場合だけ `Swim` とし、それ以外を `Human` にしていた。このため、未塗装へ出る、空中へ飛び出す、乾いた地面でShiftを押す、といった操作で原作とは異なる人型復帰が発生していた。

壁泳ぎから飛び出す処理や壁の上端へ乗り上げる処理にも、人型へ直接戻す経路がある。床の一か所だけを直すと、壁・坂・着地の境界で同じ問題が残る。

## 公開値と維持する値

[1130の能力・共通値](https://raw.githubusercontent.com/Leanny/splat3/main/data/parameter/1130/misc/params.json) と [1130のプレイヤーJSON](https://raw.githubusercontent.com/Leanny/splat3/main/data/parameter/1130/misc/SplPlayer.game__GameParameterTable.json) を直接取得した。能力配列の順序は既存調査と同じ `[High, Mid, Low]`、能力なしは最後の値である。[Leannyの能力計算コード](https://github.com/Leanny/splat3/blob/main/ability.html)

距離は既存のCG2縮尺 `S=0.5` を維持する。速度の換算は `生値 × 60 × S`。この「ワールド距離」を実世界のメートルとは呼ばない。

| 項目 | 1130の生値または既存基準 | CG2での意味 | 確度 |
| --- | --- | --- | --- |
| MoveVel_Human（能力なし） | 0.096 / F | 通常人型2.88 / 秒 | B |
| MoveVel_Stealth（能力なし） | 0.192 / F | 自インク遊泳5.76 / 秒 | B、適用条件はA/C |
| スプラシューターの射撃移動 | 0.072 / F | 2.16 / 秒 | B |
| InkRecoverFrm_Std | 600 F | 通常の空→満タン10秒、10% / 秒 | B |
| InkRecoverFrm_Stealth | 180 F | 潜伏の空→満タン3秒、約33.333% / 秒 | B |
| 射撃後の補給停止 | 20 F | 約0.333秒。補給速度とは別 | 既存の共通初期値を維持 |
| 人型からの初弾 | 3 F | 0.05秒 | 既存Cを維持 |
| イカからの初弾 | 12 F | 0.20秒、形態復帰を含めた既存の総遅延 | 既存Cを維持、後述の留保あり |

連射6F、消費0.0092/発、弾道、拡散、通常人型・遊泳速度は今回の形態修正のために変えない。乾いたイカの遅い移動を表現するため、既存の遊泳速度を下げない。

### 補給条件の判断

公開データには通常と潜伏の2種類の補給時間があるが、乾いた地面のイカ、空中のイカ、相手インク上について、それぞれ独立した補給速度や受付条件を表す値は見つからなかった。プレイヤーJSONにもこの全処理は公開されていない。

したがって、第3段階では **潜伏中だけ180F、露出した人型・イカは既存の通常600F** とする方針を推奨する。乾いたイカ・空中に通常補給を適用する厳密条件はDと明記する。射撃後の20F停止はどちらにも適用する。

**相手インクに触れたとき、タンク補給を完全停止する一次根拠は確認できなかった。** 体力の回復条件と、タンクの補給条件を混同しない。今回は新しい停止条件を追加せず、通常補給を維持するのが妥当である。残量0からでも変身でき、自色に接したときだけ高速補給へ切り替わることを回帰テストに含める。

### イカからの初弾遅延の留保

[解析者XarrotDのパラメータ説明](https://splatoonwiki.org/wiki/User:XarrotD/paramtable) は `SquidShotShorteningFrame` をイカから射撃するまでの短縮項目として説明する。武器JSONでは1Fである。一方、[同じ解析者のデータ草稿](https://splatoonwiki.org/wiki/User:XarrotD/newdata) にはイカからの初弾11Fがあり、既存調査の12Fと一致しない。同草稿には1130の対人半径と異なる数値もあるため、版・計測端点が確定しないまま総遅延を変更しない。

形態を分離した後も、変身元がイカだった事実を保持して遅延を選ぶ。`Swim`だけでなく、露出したイカ・壁泳ぎからも同じ既存12F経路へ入れる。1Fの短縮をさらに差し引くことはしない。

## 相手インクについて確認できた追加値

1130の能力なし `Low` では `OpInk_MoveVel=0.024`、`OpInk_MoveVel_Shot=0.012`、`OpInk_MoveVel_ShotK=0.5`、`OpInk_JumpVel=0.08` が存在する。前二つはそれぞれCG2で0.72 / 秒、0.36 / 秒、ジャンプ初速は2.4 / 秒に換算できる。[1130の共通値](https://raw.githubusercontent.com/Leanny/splat3/main/data/parameter/1130/misc/params.json)

これは **敵インク中の人型移動・射撃移動** の根拠であり、未塗装イカの移動速度として流用しない。相手インク上の露出イカにも同じ低速値を使う場合は、適用条件をCG2近似と記録する。空中で敵色の床の上を通過しただけで速度を落とさず、接地して該当面に触れたときに適用する。

`OpInk_DamagePerFrame=0.003`、`OpInk_DamageLmt=0.4` も存在するが、被弾履歴・猶予・最大蓄積・体力回復まで含めると今回の形態修正から広がる。プレイヤーの体力戦闘が未整備なら、敵インクの継続ダメージは次の独立した課題にする。ダミーの体力処理だけを根拠にプレイヤーも再現済みとはしない。

## 推奨する小さな修正範囲

| 状態 | 移動と表示 | 補給 |
| --- | --- | --- |
| Human | 人型。射撃時は既存の射撃移動速度 | 通常速度、射撃後停止あり |
| Squid（露出） | 乾いた床では遅く移動。空中でもイカ形態を維持し、飛び出しの水平慣性を保持 | 通常速度というCG2方針 |
| Swim（自インク潜伏） | 接地した自色面の中で既存の高速移動。露出モデルとは高さ・波紋を分ける | 潜伏速度 |
| WallSwim | 接している塗装壁の自色を照会。壁を離れたら空中のSquidへ | 潜伏速度 |

形態入力はShift、射撃の優先関係と後隙は既存どおり。タンク残量は形態を制限しない。自色の接触を失ったら潜伏を解除するが、Shiftが維持されていれば露出イカへ遷移する。乾いた床・空中の変身、普通の着地では所有者マスクや塗りスタンプを発生させない。変身演出の粒子も、塗りを起こす飛沫と区別する。

確認するケースは、未塗装・非塗装面・空中でのShift変身、空タンクでの変身、自色→未塗装→自色の往復、床と壁からのジャンプ、イカからの射撃再開、射撃停止と補給停止の区別、形態変更だけでは塗り枚数が増えないこと。基準の連射・タンク消費・CPU/GPU所有者一致の回帰テストも維持する。

未確認のまま残す項目は、原作の未塗装イカの厳密速度・加減速、空中操舵の全式、露出状態別の厳密な補給受付、イカからの初弾計測の1F差、敵インク上の露出イカの詳細、イカロール・イカノボリ・金網通過・地形の角での微小なインク拡張。今回は基本の形態と潜伏の区別を優先し、別の大型機能として混ぜない。
