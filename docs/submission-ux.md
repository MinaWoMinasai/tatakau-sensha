# 提出版UX確認（2026-09-27）

今回の変更はUI・説明・初回体験・配布準備に限定しています。新能力・敵・モードの追加はありません。標準JSONを変更前と比較し、40枚の説明以外の効果、威力、価格、レア度、対応スタイル、敵、機体、schemaが一致することを確認しました。

## 1. 施設UI

- 修理は中央の「装甲を修理」と下の「修理せず進む」の2択です。既存パネルを再利用し、新規のカード描画資源を増やしていません。
- 最大HPの50%回復、価格、現在HPを表示します。HP満タン・Cr不足は購入不可と理由を表示します。価格・回復量は従来通りです。
- 通貨地点ではカードを出さず、工房は実在する候補だけ表示します。空き枠の「候補なし」は削除しました。通常の3択は維持します。
- 選べるマスの明滅・発光を少し強め、既存の矢印、完了表示、過ぎたルートの暗転を維持しました。

## 2. 主表示

主要な遷移表示を「戦闘開始」「施設へ」「強化を取得」「装甲修理」「次の地点へ」「強化を装備しました」に整理しました。タイトルは「遠征をはじめる」、選択画面は「戦闘スタイルを選ぼう」です。ボスは移動・突進予告・連続射撃・装填などの日本語で状態を伝えます。

## 3. 初回体験

上ルートを「操作を学ぶ／初回プレイにおすすめ」、下を「説明をスキップ／操作を知っている人向け」とし、最初は上を選択します。どちらも選択でき、58 Crと同じ初期候補を得られる既存仕様を維持しています。

操作説明は1画面1内容を維持して短縮しました。工房の説明は「Crで戦車を強化します。効果はこの遠征中ずっと有効です。」とし、スキップは独立したボタンで示します。

現在のマップ式チュートリアル完了時に履修状態が保存されない不具合も修正しました。既存設定の未知フィールドを保持して一時ファイルから置き換え、不正な既存JSONは上書きしません。通常の自動テストは作者の履修記録を変更せず、提出通し検証だけ隔離フォルダーの専用マーカーと環境変数の両方を必要とします。
