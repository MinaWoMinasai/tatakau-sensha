# たたかうせんしゃ

## 起動

実行ファイル `CG2.exe` を起動してください。

## 操作

| 操作 | 入力 |
|---|---|
| 移動 | WASD |
| 照準 | マウス |
| 攻撃 | 左クリック |
| ダッシュ | 右クリック |
| ポーズ | Esc |

## ゲーム概要

3種類の戦闘スタイルから1つ選び、ランダム生成される作戦ルートを進み、戦闘で光る通貨を回収して戦車を強化し、最終ボス撃破を目指すローグライトアクションです。

## 技術面

- C++ / DirectX 12による自作エンジン
- JSONによるデータ駆動とランダム経路生成
- シューター / ドローン / 近接の3戦闘システム
- 特殊弾道・ドローン制御・近接パリィなどの戦闘処理
- F2～F6の制作ツール（制作版のみ。提出版では無効）
- 起動処理・シェーダーキャッシュ・生成テクスチャキャッシュの最適化
- 自動回帰テスト
