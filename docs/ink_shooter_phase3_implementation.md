# Ink Shooter Lab 第3段階：変身・飛沫・射撃の追加再現

2026-09-12。前段階の武器基準値（Splatoon 3 Ver.11.3.0、スプラシューター、能力補正なし）を維持し、形態と潜伏の混同、均一な飛沫、射撃処理の不足を修正した。

## 今回変わった操作と見た目

| 操作・状況 | 変更後 |
| --- | --- |
| 未塗装・空中でShift | 露出したイカに変身する。インク残量を条件にしない |
| 自インクに入る | 潜伏へ移り、移動5.76・補給33.33％/秒になる |
| 自インクを離れる | Shiftを保てばイカのまま。乾いた床では低速、空中では助走を引き継ぐ |
| 泳いでジャンプ・壁ジャンプ | イカ形態を保って飛び出す。空中では高速補給を停止し通常補給へ |
| 相手色へ接地 | 移動0.72、射撃移動0.36、ジャンプ初速2.4へ制限。塗り返せば自色として使える |
| 単発・連射の塗り | 弾ごとに落下位置・個数・幅が変わり、連射で塗りが重なる |
| 足元の塗り | 接地して足元が自色でない射撃が3〜4回続いた際に、位置・幅を変えた補助飛沫を出す |
| 壁際の足元塗り | 配置先への衝突を確認し、遮られる補助飛沫は生成しない |
| 射撃ボタンの連打 | 残り待機時間を保ち、設定の6Fより速く撃てない |
| 弾ブレ | 左右の角度分布を検証資料の式へ変更。上下照準でも角度幅が縮まらない |

露出イカは床より上に厚みを持たせ、潜伏時の平たいモデルと区別した。乾いた床・空中で変身しただけでは、塗り判定や表面の波紋を作らない。着弾時の描画専用粒子も、主弾3〜7粒、途中飛沫0〜2粒に変化を付けた。モデルは引き続きCG2の簡易形状である。

日本語設定へ「イカ（露出）／潜伏」「自分／相手の色」「接地／空中」、未塗装イカの速度、相手インクの移動値と説明を追加。「相手インクの試験帯を置く」ボタンで、開始位置の先に塗り返せる試験帯を作れる。

## 調査で確認した点と近似の区別

任天堂の更新履歴には空中でのイカ変身、自色でない場所へのイカ着地、上下照準での左右ブレの修正が記載されている。形態変更と潜伏を分ける根拠とした。[公式更新履歴](https://www.nintendo.com/en-gb/Support/Nintendo-Switch/Game-Updates/Splatoon-3-Update-History-2358763.html)

公開パラメータの途中飛沫は生成数1.5、分割数8、同一弾での間隔9.2、近端1.2。**分割数8を「毎弾8個の飛沫」とは扱わない。** ただし小数の丸め方、位相順序、乱数処理の実コードは確認できていない。CG2では1・2個の予算を交互に割り当て、8つの距離区画を巡る設計とした。[固定版の武器データ](https://raw.githubusercontent.com/Leanny/splat3/7280ff9cde8bb1c5dcef46c700c326471584d2e6/data/parameter/1130/weapon/WeaponShooterNormal.game__GameParameterTable.json)

位相順序はリセット時だけ選び、その後は同じ順序で巡回する。これにより任意の連続8発が全区画を通る。距離の小さな揺らぎ、幅、横ずれ、周辺の小粒数は毎弾変わる。足元の発生条件もCG2の近似であり、公開配列の[4]から原作の内部条件を復元したとはしていない。詳しい出典と検証は [飛沫・足元塗りの調査](ink_shooter_phase3_paint_research.md) に記載した。

未塗装イカの速度0.9、露出イカへの通常補給の適用、空中の操舵と慣性、敵色上のイカへの人型減速値の適用はCG2の調整である。通常／潜伏補給の600F／180Fと、相手色での人型移動値は公開値を使う。敵インクでタンク補給を止める根拠は確認できなかったため停止条件は追加しない。[移動・補給の調査](ink_shooter_phase3_movement_research.md)

左右ブレの式は `s × pow(u, log(b) / log(0.5))` と独立した左右符号。bを外周へ飛ぶ確率としていた以前の近似を置き換えた。幅4.86°／ジャンプ11.66°、通常bias上限0.25／ジャンプ0.40を維持する。崖から歩いて落ちただけではジャンプ用のブレにしない。初弾3F／イカから12Fは既存基準を保ち、浮動小数点誤差による1更新分の遅延も除去した。イカ初弾の資料間の1F差は未確定事項として残している。[射撃の調査と資料](ink_shooter_phase3_shooting_research.md)

## 実装上の分離

- `InkTypes.h`：Human / Squid / Swim / WallSwim。接地・自色・相手色を形態と分けて保持。
- `InkEmissionPattern.h`：主弾ごとに一度だけ計画を作り、その弾に保存。主弾が距離を通過した場合だけ飛沫を出し、壁や標的に当たれば以降の生成を打ち切る。
- `InkSpreadPattern.h`：水平偏差の数学処理。照準が垂直でも有限の方向を返す。
- `InkSimulation.cpp`：移動、補給、射撃、衝突、同一スタンプによるCPU/GPU塗り更新。
- `InkShooterScene.Visuals.cpp`：描画専用の粒子変化。弾道・塗りの乱数を進めない。
- `InkShooterScene.Fidelity.cpp`：27秒の追加検証。従来の45秒検証も維持。

射撃、飛沫計画、ブラシ、描画専用粒子は乱数を分ける。飛沫の外観設定を変えても主弾の弾道は変わらない。1発の計画容量12個は防御上限であり通常生成数ではない。計画上の距離上限は主弾の既存消去条件と同じ60、実際の生成は衝突までの掃引区間に制限される。

## 検証

`project/tools/test_ink_simulation.ps1` でSimulationと生成計画器の両方をコンパイル・実行する。

- 60Hz／120Hzで初弾3F／12F、連射6F、押す・離すを繰り返した場合の待機時間を確認。
- 未塗装、空中、射撃に足りない残量、壁ジャンプ、通常／潜伏補給、敵色上の速度とジャンプを確認。
- 16回の単発射撃で、実際に衝突した途中飛沫が1個・2個に変化することを確認。近い壁の先やパネル裏へ飛沫を生成しないことも確認。
- ブレの中央値、左右対称、上下・垂直照準の角度幅、塗り設定からの弾道の独立性を確認。
- 標準回帰の25条件に加え、独立診断の125条件（25の発射履歴×5方向）でも、1秒連射後に足元から着弾付近へCPU所有者マスクが連結。単発や任意の障害物上で連結を保証する仕様ではない。
- 7,200更新・120Hzの負荷シナリオ：326発、同時主弾最大6、途中飛沫最大7、1更新の塗り最大17。全弾・飛沫の消去と固定サイズの所有者マスクを確認。
- 生成計画1,024発で割当て1,536個。異常値・実行中の設定変更9,600ケースでも容量超過や非有限入力を生成しない。

Development・Releaseのビルド成功。最終Development版の27秒シナリオ、最終Release版の45秒シナリオを実行し、どちらも起動時を含むD3D12診断はエラー0・警告0だった。デバッグレイヤー有効、GPU Based Validationは無効。日本語設定を実際に開閉し、新しい状態・値・試験帯ボタンの表示も確認した。

Developmentのログでは、残量0.6401％・自色なしでSQUID、泳ぎジャンプ中は自色接触なし・速度5.76、着地後はSWIMへ戻ることを確認。残量が厳密に0の変身・潜伏は、補給停止中の独立回帰テストでも確認した。Releaseの従来検証では坂の登坂、壁泳ぎで高さ6の上端へ到達し、乾いた上面でSQUIDを維持。ダミーは36ダメージ、3発で撃破・復活した。

## 残る再現上の制約

原作の乱数列や塗りテーブルを取得した完全再現ではない。簡易モデル、カメラ・ジャンプ・衝突形状、床や壁のマスク解像度もプロトタイプのまま。可変ジャンプ、イカロール／イカノボリ、金網通過、敵インクのプレイヤー体力ダメージ、弾への移動速度継承は未実装。存在だけでなく発動条件や係数を確認してから追加する。

提供された原作動画は飛沫のまとまり・表面の形・姿勢の定性的比較に使用した。30fpsの映像と不明な入力履歴から、原作の乱数分布や数フレームの遅延を測定したとは扱わない。
