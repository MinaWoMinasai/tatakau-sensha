# 作品画像の追加

このフォルダーに実際のゲームから撮影した画像を置き、ルート README の画像コメントを有効にしてください。

| 推奨ファイル名 | 撮影する内容 |
| --- | --- |
| `combat.png` | 自機、敵、HP・スタミナ、攻撃やネオン表現が分かる戦闘 |
| `route.png` | 次に進める地点と分岐を示す作戦マップ |
| `upgrades.png` | 系統選択や強化カードの候補 |

制作 UI や個人のウィンドウが写らない画像を使用してください。現在ここにはゲーム画像を追加していません。ファイル名だけを先に決め、実装されていない画面のイメージ画像は掲載していません。
