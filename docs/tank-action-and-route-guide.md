# 戦闘と新しい作戦ルートの遊び方

この版では、遠征ごとに変わる作戦マップを進み、回収した通貨で射撃・近接・体当たりの組み合わせを作ります。以下の金額や候補数は標準設定です。

## 操作と戦闘

| 操作・表示 | 内容 |
| --- | --- |
| WASD | 移動。慣性があるため、キーを離すと滑らかに減速します。 |
| マウス／左クリック | 狙いを向けて攻撃。押し続けても攻撃できます。 |
| 右クリック | スタミナを使ってダッシュ。移動入力の方向へ、入力がなければ照準方向へ進みます。 |
| 緑のバー | HP。0になると遠征終了です。 |
| 黄色のバー | スタミナ。ダッシュしていない間に回復します。HPの下に表示されます。 |

HPとスタミナは左上と自機に追従するバーの両方で確認できます。通常の戦闘はWASDと左右クリックだけで操作できます。

主砲は**1砲塔につき1回1発**です。砲塔が増えた機体では、それぞれの砲塔から発射します。以前の拡散強化による追加弾・命中時の分裂は廃止しました。反射・貫通・追尾は引き続き組み合わせられます。

導入の強化を購入またはスキップした後に、**シューター・ドローン・近接**から系統を選びます。基本3機体は同格で、選択した時点から主装備を使えます。導入で買った強化・現在HP・スタミナ・通貨は引き継ぎます。

| 系統 | 基本攻撃 | 育て方の例 |
| --- | --- | --- |
| シューター | 左クリックで1門から射撃。 | 追尾、壁反射、敵の貫通、ダッシュ後の射撃強化。 |
| ドローン | 追従する3機が、左クリック中に照準へ射撃。 | 支援機追加、高威力の集中射撃、敵弾を消す迎撃弾。 |
| 近接 | 左クリックで3段斬り。3段目は広い薙ぎ払い。 | 間合い、連撃速度、3段目の威力、体当たりと押し出し。 |

以後の工房は**汎用＋選択系統に有効な強化だけ**を提示します。攻撃力・攻撃速度などの基礎強化は3系統すべてに有効です。前提未取得・効果取得済みの商品や、他系統への武装切替は候補から除外します。複合商品も全効果が有効で未取得の場合にだけ提示します。進化も同じ系統内で選び、進化せず改造を重ねて進むこともできます。

ダッシュには直前の速度の**20%**が残ります。開始直後に敵本体へ当たると、敵を吹き飛ばす**SLAM**が発生します。同じ敵へのダメージは1回のダッシュにつき1回。ボスにも効きますが、押し出しは小さく、攻撃を中断させ続けることはできません。

ジャスト回避は標準では発生しません。「ジャスト回避」強化を取得すると、ダッシュ開始直後の**敵弾**への接触で発動します。敵本体への接触は、取得後もSLAMです。

## 最初の2ルート

最初だけは、必ず上下2つに分かれます。

| ルート | 1マス目 | 2マス目 |
| --- | --- | --- |
| 上：操作を学ぶ | 射撃・撃破、通貨回収、HPとスタミナ、ダッシュを順に練習します。 | 3つの弱めの強化から1つ購入、またはスキップします。 |
| 下：訓練を省略 | 上のルートの撃破・突破報酬と同額の**38Cr**を受け取ります。 | 上と**同じ3候補・同じ価格**で購入、またはスキップします。 |

上のルートでは、最初の説明とHP・スタミナの説明中に戦闘が止まり、画面を暗くして対象を示します。左クリックで説明を進めます。ダッシュを使っていない場合や、ダッシュ中に被弾した場合は練習が続きます。

導入の強化候補は攻撃力・攻撃速度・移動・最大HPの汎用4種類から挑戦ごとに3つ選ばれ、**各15Cr**です。初期所持金20Crとは別に、どちらのルートも合計38Crを得られます。2マス目を終えて機体系統を選ぶと、同じ通常ルートへ合流します。

## 強化カードの見方

コモン（白）、アンコモン（黄緑）、レア（水色）、エピック（紫）、レジェンダリー（虹色）の5段階です。色だけでなく枠の構造・光・粒子量も変わり、名称を併記します。進化の段階とレア度は別の情報です。機体系統の最初の3択は同じ基本枠です。

カーソルを合わせたカードだけ、枠内の短い動作デモが進みます。系統選択では基本攻撃、特殊強化では現在／取得後の例を表示します。HPなど動作で示しにくい数値強化は説明で確認できます。デモは理解を助ける模式的な表示で、実際の戦闘の複製や正確なDPS計測ではありません。デモを見ても通貨・HP・取得内容・抽選結果は変わりません。

標準の抽選は系統向け2枠と汎用1枠を優先し、不足時は有効な候補で補います。レア度の抽選重みは60・26・10・3・1です。これは商品の相対的な重みで、各レア度がその割合で出現する保証ではありません。取得済み効果などで候補数も変わります。

## マップと通貨

最初の2マスと最終ボスを含め、1回の進行で通る地点は**18～22マス**です。分岐の数、施設・戦闘の配置が変わり、同じ種類が3連続しないように生成します。最後は1つのボス地点へ合流します。進化地点には迂回できるルートがあります。

次に進める光る地点を左クリックします。動く矢印も選べる地点を示します。クリア済みは緑のネオン文字「完」、過ぎた未選択ルートは暗く表示されます。長いマップは画面の左右ボタンで移動できます。改造・進化は候補をクリックして購入し、「購入せず進む」も選べます。

HPの横にある**光る丸と数字**が所持通貨Crです。撃破時に出る光球へ近づくと、光球が所持金表示へ飛び、音と発光とともに加算されます。戦闘終了時には残りも回収されるため、毎回すべて拾い歩く必要はありません。通貨は改造・進化・修理に使い、次の遠征へは持ち越しません。

## 編集と調整

| キー | 編集するもの |
| --- | --- |
| F4 | 戦闘部屋の敵・ブロック・開始位置・目標。 |
| F5 | 作戦ルート。「新規遠征ごとにランダム生成」を外すと、表示中の経路を固定して編集できます。 |
| F6 | 改造、敵、自機の種類。強化の対応系統・5段階のレア度、進化機体の系統・レア度も編集できます。 |

ランダムになるのは経路と部屋の組み合わせです。戦闘部屋の地形自体は、F4で作った部屋を利用します。また、F6は用意された効果・AIを組み合わせるエディターで、新しい効果やAIプログラムを自由に記述する機能ではありません。

初期機体でも改造を組み合わせて攻略でき、進化を必須にしない設計です。敵の強さ、近接の間合い、通貨量を含む難易度は引き続き調整対象です。このガイドは実装内容の説明であり、各ビルドでのクリアや難易度の検証完了を意味しません。
