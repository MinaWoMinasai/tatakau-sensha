# コア争奪戦（試作）の遊び方

図形を倒して資材を集め、金色の共有コアをライバルと奪い合いながら戦車を改造する、リアルタイムのアリーナ戦です。ライバルを倒すと勝利します。

## 起動

リポジトリのルートから、ビルド済みのゲームを起動します。

```powershell
.\project\tools\run_tank_run.ps1
```

通常のタイトルでは「コア争奪戦（試作）」を選ぶか、F9を押します。上下キー／W・Sで選択し、Enter／Space／項目のクリックで決定します。

既定はDevelopment版です。Release版は `-Configuration Release` を指定します。Debug指定で実行ファイルがない場合はDevelopment版を使用します。未ビルドの場合は、Visual Studioで `project/CG2.sln` を対象構成・x64でビルドしてください。

## 戦闘の流れ

1. ツイン・マシンガン・オーバーシアの3機体から選ぶ。
2. 反射・突撃・指揮の3主軸コアから選ぶ。開始時から3×3の組み合わせを試せる。
3. 図形を倒して資材を集め、金色のコアを先取りする。資材が足りたら任意のタイミングでE改造。
4. 戦闘時間150秒で最終決戦へ移り、ライバルが採集をやめてこちらを追う。途中撃破でも勝利。

改造・一時停止・Cの進化画面では、戦闘、決戦タイマー、コアの再出現が停止します。待つだけで改造は増えません。最終決戦の長さは倒す速さで変わります。

ライバルは採集中、通常図形よりコアを優先し、プレイヤーが近づくと迎撃に切り替えます。攻撃は照準を固定する予告、射撃、反撃できる隙の順に進みます。散弾、隙間のある環状弾、掃射を見て位置を変えてください。

## 資源と改造

| 対象 | ルール |
|---|---|
| 通常の図形 | プレイヤーの撃破で資材+1と種類ごとのEXP。連続撃破はCHAIN表示 |
| 金色の共有コア | 3か所。HP42を双方の射撃で削り、最後の有効な攻撃で所有が決まる |
| プレイヤーが確保 | 資材+12、EXP30、HP12回復。次の改造に未所持のレア候補を保証する権利を1回分得る |
| ライバルが確保 | レベル+1、最大HP+35。Lv6・最大HP・総回復量に上限がある |
| 再出現 | 確保から20秒後、同じ地点に新しいコアが現れる |

コアは固定位置にあり、戦車やドローン本体の接触では取得できません。ドローンの弾はプレイヤーの攻撃です。雑魚Shooterの流れ弾もコアを取得しません。コアの報酬は通常図形の撃破報酬とは重複しません。回復は最大HPまでです。

ライバルが通常図形を倒した場合はHPが最大1回復するだけで、レベルは上がりません。コアによる最大HP増加時の回復も含め、回復には試合全体の予算があります。

E改造の費用は順に **12／16／20／24／28／28**、最大6回です。全12種類は各1回までで、取得済みの改造は再登場しません。レア保証は未所持レアがある場合に働き、保証がなくてもレアが出ることがあります。

## 開始機体と主軸コア

| 開始機体 | 特徴 |
|---|---|
| ツイン | 交互に撃つ2つの砲口。狙いを絞りやすい |
| マシンガン | 広がる連射。近距離でまとめて当てる |
| オーバーシア | 照準位置へ最大6機のドローンを指揮 |

| 主軸コア | 開始時から働く効果 |
|---|---|
| 反射 | 跳弾、弾数+2、弾速+25%、1発の威力55%。細い扇状の弾で壁を使う |
| 突撃 | 弾数+4、1発の威力45%、弾速85%、通常の発射間隔1.6倍。ダッシュ後1秒は散開角が半分、発射間隔がさらに0.65倍 |
| 指揮 | ドローン機体は上限+2で最大8機。他の機体には援護2機。ドローンの発射間隔0.8倍、ダッシュで次の射撃を促す |

## 12種類の改造

倍率は主軸や他の改造と組み合わさります。実際の弾ダメージは整数化されます。

| 改造 | 効果 |
|---|---|
| 反射コーティング | 壁で弾が反射。反射コア所持時は弾速がさらに+20% |
| 重い弾頭 | 威力+70%、弾速-28%、発射間隔+20% |
| 高速装填 | 発射間隔-35%、威力-20% |
| 軽量スラスター | 移動速度+18%、ダッシュ速度・スタミナ回復+25%、ダッシュ待ち時間-20% |
| 回避コンデンサ | ジャスト回避でHP4・スタミナ1回復。射撃強化が3.5秒続く |
| 予備装甲 | 最大HP+25%、取得時にHP30回復 |
| 援護ドローン | 援護が2機増える。指揮コア＋ドローン機体は最大10機 |
| 迎撃弾 | 敵弾を消す力が1→3。敵本体への威力とは独立 |
| RARE 分裂砲口 | 弾数+2、1発の威力-25%。扇状に広がる。通常射撃の弾数は上限7 |
| RARE 弱誘導弾 | 前方の近い敵へ弾が緩く曲がる。壁を貫通する効果はない |
| RARE ダッシュバースト | ダッシュ開始時に8方向へ発射 |
| RARE オーバードライブ | ダッシュ後1.2秒、発射間隔が半分。発動間隔4秒。ジャスト回避なら効果2.4秒 |

ドローンの弾にも反射・誘導・分裂などが適用されます。Cで進化しても主軸と改造は引き継ぎます。この試作の進化候補は射弾・ドローン系に絞り、レーザー・地雷・近接専用機は対象外です。

## 操作と演出

| 操作 | 内容 |
|---|---|
| WASD／マウス | 移動／照準 |
| 左クリック長押し | 射撃。指揮機体ではドローンを操作 |
| 右クリック | ダッシュ。スタミナと待ち時間が必要 |
| E | 資材が足りる時に改造画面を開く |
| C | 進化画面を開閉。EXPで条件を満たした上位機体を選ぶ |
| 左右キー／A・D、Enter／Space | 開始機体・主軸・改造の選択と決定。数字1〜3やクリックでも決定 |
| Esc | 一時停止／再開。進化画面は先に閉じる。停止画面からタイトルへ戻れる |
| 結果画面 | 矢印／W・Sで選択、Enter／Spaceで決定。1／2やクリックでも決定 |
| F10 | 画面を `project/generated/tank_run/` に保存 |

移動・停止の反応を速め、ダッシュ開始時の方向入力をすぐ反映し、その加速が直後の移動処理で消えにくくしています。資源確保の金色の波紋、CHAIN表示、コアの被弾フラッシュで結果を伝えます。

床格子を控えめにし、弾の軌跡・粒子・ネオンラインのBloomを復元しています。追加のポスト処理による輪郭線は無効ですが、戦車・図形・壁のネオンの枠線は描画します。

リトライやタイトルへの移動で、その試合の改造と進行はリセットされます。恒久強化はありません。通常モードの能力値振り分けは、このモードでは使いません。

## テストで確認する項目

リポジトリのルートで実行します。単体テストには既存のVisual Studio C++ツールが必要です。

```powershell
# 進行・ボス予告・改造倍率
.\project\tools\test_tank_run.ps1

# 衝突、共有HP、所有、報酬、ライバルの成長上限
.\project\tools\test_tank_collisions.ps1

# ビルド済みDevelopment版で画面遷移と結果表示を自動確認
.\project\tools\run_tank_run.ps1 -Validate
```

進行テストでは資材と費用、選択中の停止、レア保証、早期勝利・最終決戦を確認します。倍率テストは主軸なしを含む4状態×12改造の有無で **16,384通り** を確認します。数値の合成テストであり、全構成の戦闘バランスを保証するものではありません。衝突テストは本番メソッドを取り込み、迎撃の処理順、取得の重複防止、接触・Shooter弾の除外、コア優先と成長上限を確認します。

`-Validate` は子プロセスに `CG2_TANK_AUTOTEST=1` を渡し、最終決戦までを24秒に短縮します。プレイヤー無敵・自動選択・コアへの強制ダメージ・資材追加を使い、最終決戦開始から5秒後にボスを強制撃破する動作確認です。実戦の難易度、取得速度、撃破時間の評価には使えません。

自動確認は非表示で開始し、終了時に自ら閉じます。起動スクリプトは完了を待ちません。結果JSONと画像は `project/generated/tank_run/` に出力されるため、JSONの更新日時と `completed` を確認します。通常起動は自動確認フラグを外し、起動後に呼び出し元の環境変数を復元します。

手動では、各メニューの表示中に戦闘が止まり、候補の決定入力が射撃やダッシュに流れないことを確認してください。さらに、コアを先取りする判断が生まれるか、主軸と改造で射線や立ち位置が変わるか、ボスの予告を読んで反撃できるかを確かめてください。
