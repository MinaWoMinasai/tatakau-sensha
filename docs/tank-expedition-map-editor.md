# 作戦マップと遠征エディター

遠征は「作戦マップ → 戦闘・施設 → 作戦マップ」の流れで進みます。標準設定では遠征ごとに進路が変わり、光っている地点を選びます。反射・貫通・追尾に加えて近接ブレードとダッシュ体当たりを組み合わせられます。主砲は1砲塔につき1回1発に統一し、拡散強化の追加弾と分裂を廃止しました。

新しい操作・導入ルート・通貨回収の説明は[戦闘と新しい作戦ルートの遊び方](C:/Users/k024g/OneDrive/デスクトップ/自作エンジン2/docs/tank-action-and-route-guide.md)にまとめています。この文書では、主に編集方法と保存先を説明します。

## 遊び方

タイトルから遠征を開始します。直接起動する場合は、リポジトリで次を実行します。

```powershell
./project/tools/run_tank_expedition.ps1 -Configuration Release -SkipTitle
```

開始時は基本の単発射撃です。以前のCYCLE設計選択と、購入数に応じて隠れた主軸が起動する仕組みは作戦モードでは使用しません。購入した改造によって性能を変え、進化地点では基本進化と追加機体を選べます。進化地点には迂回路があり、初期機体でも改造を組み合わせて進める設計です。

最初は必ず上下2ルートです。上は「チュートリアル・戦闘 → チュートリアル・強化」、下は「資材支給 → 初期強化」で、その後合流します。どちらも初期所持金20Crに加えて38Crを得られ、導入の改造は同じランダム3候補・各15Crです。購入せず進むこともできます。

| 表示 | 地点で行うこと |
| --- | --- |
| 戦 | 配置された敵・資源を破壊して通貨を回収 |
| 強 | 精鋭戦闘、または制御装置の確保 |
| 改 | 通貨で改造を1つ購入。効果を組み合わせる |
| 進 | 機体の砲門・射撃構成を変更。HPと改造を引き継ぐ |
| ＋ | 最大HPの50%を修理。満タンなら支払わず通過できる |
| 〇 | 訓練を省略し、上ルートと同額の通貨を受け取る |
| 核 | 最終ボスとの戦闘 |

遠征では経験値とレベルアップを通貨 **Cr（回収資材）** に置き換えました。撃破報酬と区画突破報酬で増え、改造・進化・修理に使います。開始時は20Crです。通貨はその遠征専用で、次の挑戦には持ち越しません。従来のアリーナの経験値システムはそのままです。

所持金はHPの横の光る丸と数字で表示します。撃破時の光球に近づくか戦闘を終えると、光球が所持金表示へ飛び、到着時にSEとともに加算されます。HPは緑、スタミナは黄色で、左上と自機に追従する位置の両方に表示します。マップの完了地点は緑の「完」、通過した未選択ルートは暗く表示し、選べる地点を動く矢印でも示します。

施設では1回購入すると次へ進みます。購入せず進むこともでき、資金不足で止まりません。改造はその地点で選ばれた最大3候補を表示します。機体など候補が3件を超える場合は画面下のボタン、または **Q / E** でページを切り替えられます。追加した種類も候補になります。改造の同じ効果は重複しません。

戦闘の基本操作は **WASDで移動・マウスで照準・左クリックで攻撃・右クリックでダッシュ**です。マップや施設もクリックと画面上のボタンで操作できます。以下の数字・矢印キーなどは任意の補助操作です。

| キー | 操作 |
| --- | --- |
| クリック / 数字 / 左右＋Enter | 次の地点・購入候補を選択 |
| 画面の左右ボタン / Q / E / ホイール | 作戦マップを横移動（長いマップの場合） |
| G | 戦闘中に作戦マップを確認。もう一度GまたはEscで復帰 |
| TAB | 現在の構成を確認 |
| Esc | 一時停止・タイトルへ戻る |
| F1 | 既存のパフォーマンス表示 |
| F2 | 既存の数値バランス調整 |
| F4 | 部屋の配置エディター |
| F5 | 遠征の進路エディター |
| F6 | 改造・敵・自機の種類エディター |

マップ確認、構成確認、エディターを開いている間は戦闘が止まります。Releaseでも編集できます。既存の `CG2_PERF_DISABLED=1` でImGui全体を無効化した場合は、F1・F2・F4〜F6の画面も無効です。通常起動では有効です。

## 3つのエディターの使い分け

### F4：部屋を作る

1. 既存区画を選ぶか「新しい区画」「区画を複製」を押します。
2. 床・通常壁・危険壁・敵／資源・自機開始・目標の道具を選び、グリッドへ配置します。
3. 目標を「配置した敵・資源をすべて破壊」「装置3個を確保」「ボス撃破」から選びます。
4. `Apply`で適用、`Save`で保存します。配置は次にその部屋へ入ったときに反映されます。

左クリックで配置、壁と消しゴムはドラッグに対応します。右クリックで敵・壁を消去できます。配置済みの敵を選ぶと種類・座標・HP上書きを編集できます。**HP上書きが0ならF6の標準HP**を使用します。自機とボスの開始位置、制圧目標の位置も変更できます。

壁への埋まり、配置同士の重なり、到達できない場所、存在しない種類などを検査し、不正な配置は適用・保存しません。外周と基本グリッド寸法は現在のエンジンに合わせて固定です。

### F5：どの順番に遊ぶかを作る

「新規遠征ごとにランダム生成」が標準です。導入2地点と最終ボスを含めて**18～22地点を通る経路**を生成し、同種3連続を避けます。分岐数と戦闘・施設の配置が変わり、最後は1つのボスへ収束します。進化には迂回路があります。F5では確認用シードでプレビューでき、チェックを外すと表示中の経路を固定して編集できます。

固定編集では上部の経路図をクリックして地点を選びます。地点の種類、編集用の名前、使用する部屋、戦闘の段階、突破報酬、施設価格を変更できます。接続先のチェックで進路を作り、「施設を追加」「分岐として複製」で増やせます。

接続は右の列へ進みます。行き止まりや循環、到達できない地点、部屋の参照切れは保存前に検査します。最終ボスにはF4でボス目標にした部屋を指定してください。通常の改造地点の価格は最低価格で、実際の支払額はF6の個別価格との大きい方です。追加機体の進化価格も同様です。導入2ルートの改造だけは同条件にするため、地点の価格を使います（標準15Cr）。

**進路の変更は次の遠征から反映**します。現在の進路・残高は変わりません。Escでタイトルへ戻り、新しい遠征を始めると適用内容を試せます。

### F6：種類を増やす

「新規作成」「選択を複製」で独立したIDを持つ種類を増やせます。

- 強化：名前・説明・価格・対応系統・5段階レア度と、既存効果から最大4つの組み合わせ。精密指揮・迎撃護衛・連撃駆動・終撃増幅を追加しました。基本ブレードは系統選択で装備するため通常の販売候補から除外します。
- 敵：行動型・HP・接触／射撃ダメージ・移動速度／攻撃間隔倍率・弾倉数・装填時間・撃破通貨・ネオン色。追加したIDはF4の配置パレットへ反映。
- 自機・進化：系統・5段階レア度・基本型・砲門数・扇の角度・威力／間隔／弾速・支援ドローン・交互射撃・反射・貫通・形状・色・価格。弾数は1砲門につき1発で固定です。追加した機体は同系統の進化地点へ反映。

追加内容は実際の戦闘に使われます。すでに出現済みの敵や装備済みの機体は、その場で置き換えません。敵は次の出現、機体は次の選択で反映されます。完全に新しいAIの行動や新しい効果そのものは、引き続きコードの追加が必要です。

遠征の基礎強化は、重弾の威力増加25%、速射の発射間隔短縮25%、推進器の移動速度増加12%、装甲修復の最大HP増加15%を上限にしています。F2に以前の大きな成長値が残っていてもこの上限を使い、上限より低い設定値は反映します。

## 保存と現在の収録内容

`Apply`はアプリを開いている間の適用です。次の遠征にも保持します。次回起動にも残したい場合は `Save` を押してください。`Reload`は最後に保存したファイルを読み直します。保存時に問題があれば、それまでのデータを保持します。

| データ | 保存先（project以下） |
| --- | --- |
| 部屋6種類（導入訓練用の部屋は起動時に追加） | `resources/maps/expedition_layouts.json` |
| 進路 | `resources/configs/expedition_map.json` |
| 強化26種類・敵11種類・追加機体8種類 | `resources/configs/expedition_content.json` |
| 数値バランス | `resources/configs/tankExpeditionBalance.json` |

標準の進路は毎回18～22地点を通るランダム経路です。シューターでは既存の基本進化4種類も選べます。危険回廊には高速狙撃兵、防衛装置区画には重装突進兵を配置しています。F4の部屋を組み合わせて戦闘を構成するため、地形自体をその場で自動生成する方式ではありません。

種類データはschema 2へ更新しました。旧schema 1も読み込め、対応系統を効果から推定し、旧レア度0／1／2をコモン／レア／レジェンダリーへ移行します。作者が作ったIDや数値を一律に既定値へ戻す方式ではありません。適合しない効果を混ぜた強化や、ドローンを持たないドローン機体などは保存前に検査します。

## 機動戦と操作の反応（9月26日更新）

敵を倒すまで正面から撃ち続ける戦闘から、射撃位置・攻め時・優先目標を選ぶ戦闘へ改良しています。

| 行動型 | 動きと攻め時 |
| --- | --- |
| Charger / 突進兵 | 追跡して接近し、予告方向へ突進。停止後に側面を攻撃 |
| Sniper / 狙撃兵 | 射線を確保し、接近されると後退。固定された照準を避けて接近 |
| Skirmisher / 機動射撃兵 | 横移動、3発弾倉、短い横ダッシュ。装填中は動きが鈍る |
| Flanker / 接近散弾兵 | 接近と離脱、2発の散弾。距離を取り、装填中に追撃 |
| Suppressor / 制圧射撃兵 | 扇状の5連射で進路を制限。横を回るか長い装填中に集中攻撃 |

頭上・機体後部の短い目盛りが残弾、水色のゲージが装填です。ダッシュには方向予告があり、常に弾を避け続けるAIにはしていません。初期の部屋も新行動型を混ぜた編成へ変更しました。

最終ボスは距離を調整しながら横移動し、狙い撃ち・扇状射撃・掃射を切り替えます。4発の弾倉を使い、方向を予告したダッシュの後に装填します。HP半分から第2形態になり、5発弾倉と機動力の高い攻撃へ移ります。HPを大量に増やす変更はしていません。

F6で射撃役の弾倉数と装填時間を変更できます。0は行動型の標準値です。F2のボスHP・弾速・ダメージは有効ですが、旧ボス用の弾数・攻撃間隔は新ライバルでは無効と表示されます。新ライバルの予告・弾倉周期はコード側の行動設計です。

マップではホバー時の発光・拡大、経路を流れる光、選択音が反応します。出撃・区画突破・購入は約1秒のカーテン遷移を通し、完全に覆われた時点で切り替えます。遷移中は戦闘と選択入力を停止するため、連打による二重購入や暗転中の被弾を防ぎます。命中は局所的な火花、撃破はリング・破片・小さな振動で表現しています。

参考作品の採用理由は [戦闘と演出の調査メモ](tank-combat-feel-research.md) に記載しています。難易度や各ビルドの有利不利は、実際の試遊で引き続き調整する対象です。

ランダム経路と固定編集の両方に対応しています。イベントの文章分岐と途中セーブはまだ追加していません。用意された部屋・施設・効果・AIを編集して遊びの組み合わせを増やせますが、新しい地形生成規則や効果・AIプログラムそのものにはコードの追加が必要です。

## 検証

### 系統選択・カード演出の追加検証

`test_tank_experience_runtime.ps1 -Configuration Release -Route Upper -Style Melee` と、`-Route Lower -Style Shooter`／`-Style Drone` で実行ファイルを確認しました。3系統とも、基本装備の即時適用、系統に合うショップ候補、同系統への有料進化、選択・進化前後のHPと取得改造の保持を通過しています。ドローンは選択確定時点で3機あることも検査します。

| 基本装備 | 実攻撃による標的HPの変化 | 確認したもの |
| --- | --- | --- |
| シューター | 500 → 476 | 弾あり、斬撃なし。 |
| ドローン | 500 → 469 | 3機の即時装備、左クリックで弾あり、斬撃なし。 |
| 近接 | 500 → 481 | 斬撃・吹き飛ばしあり、プレイヤー弾0。 |

導入の購入とスキップ後は、それぞれ43Cr／58Crを維持します。今回の固定シードの導入候補は攻撃力・推進器・攻撃速度です。最初の通常戦闘だけ静止した高HP標的へ置き換え、その後の戦闘は無敵化・強制クリアで進行を確認しています。上ルートのチュートリアルは実際の射撃・回収・回避で通します。これは全ビルドの実力クリアの証明ではありません。

結果と画像は `project/generated/experience_validation/upper_melee`、`lower_shooter`、`lower_drone` に保存します。`rarity_0`～`rarity_4` は5段階の外観を比較する検証専用表示で、通常の機体系統3択は常に同じ基本枠です。

純粋なコンテンツ検証では、512シード×3系統の適合候補、12,000シードのレア度抽選傾向、旧schemaの作者データ保持を確認します。`test_tank_reward_cards.ps1` は43万サンプル以上の表示領域、近接・追尾・反射・貫通の差、非ホバー中の停止を検証します。Playerの実コードを抽出した検証では、選択時のHP・スタミナ・改造保持、ドローンの非クリック時発砲0、改造と進化倍率の合成、他系統への進化拒否を確認しています。

Release・Developmentのビルドは成功しました。従来の固定10地点マップも購入3回・進化1回・修理1回を含めて通過しました。通常起動の画面クリックでは、下の導入ルートで58Crを受け取り、装甲修復を購入してHP138/138・43Crとなり、その値を保って系統選択へ進むことを確認しています。ホバー中のドローン実演と、系統選択中のポーズ／再開も確認しました。

### これまでの戦闘・進路検証

今回の最終Release版でも慣性変更後のAI実動作を再検証し、6タイプすべて通過しました。ボスは25秒で25回の発射・5回のダッシュ・5回の装填。全タイプで壁へのめり込み、ダッシュの壁抜け、装填中の発砲は0件でした。移動標的は無敵で、第2形態の確認にはボスHPを調整しています。

`test_tank_expedition_map.ps1`、`test_tank_expedition_rooms.ps1`、`test_tank_expedition_content.ps1`で、状態遷移、全経路、支払い、重複報酬防止、配置、種類参照、不正JSON、保存・再読込を検証できます。既存の戦闘・弾・衝突・進化・チュートリアルの回帰テストも実行しています。

`test_tank_expedition_map_runtime.ps1`は実際のRelease実行ファイルで、マップ開始から購入・修理・追加機体への進化・装置確保・ボス突破を通します。結果と画面は `project/generated/expedition_map` に出力されます。これは進行の検証のため敵撃破を自動化したもので、難易度の適正を証明するテストではありません。

手動ではF4の配置追加と保存→実際の戦闘への反映、F5の設定保存と現在残高の保持、F6の複合改造の追加・保存・再読込、Gのマップ表示中の戦闘停止を確認しました。確認用の変更は元の既定データへ戻しています。

9月26日の追加検証では、`test_tank_presentation.ps1`で暗転中央での一度だけの切り替えと長いフレーム時の停止契約、`test_rival_boss_combat.ps1`でボスの弾倉・予告・第2形態を検証します。`test_tank_combat_runtime.ps1 -Configuration Release`は実際の敵5行動型を各11秒、ボスを25秒動かして計測します。
