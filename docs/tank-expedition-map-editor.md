# 作戦マップと遠征エディター

遠征を「作戦マップ → 戦闘・施設 → 作戦マップ」の流れに変更しました。最初から進路が見え、光っている地点を選んで進みます。戦闘操作と既存の跳弾・分裂・追尾などの組み合わせは引き継いでいます。

## 遊び方

タイトルから遠征を開始します。直接起動する場合は、リポジトリで次を実行します。

```powershell
./project/tools/run_tank_expedition.ps1 -Configuration Release -SkipTitle
```

開始時の3つの「設計」は、主軸と基本進化の方向を決めます。どれも最初は基本の単発射撃で、改造を2つ購入すると主軸が起動します。後の進化地点では、基本進化に加えて追加機体も選べます。

| 表示 | 地点で行うこと |
| --- | --- |
| 戦 | 配置された敵・資源を破壊して通貨を回収 |
| 強 | 精鋭戦闘、または制御装置の確保 |
| 改 | 通貨で改造を1つ購入。効果を組み合わせる |
| 進 | 機体の砲門・射撃構成を変更。HPと改造を引き継ぐ |
| ＋ | 最大HPの50%を修理。満タンなら支払わず通過できる |
| 核 | 最終ボスとの戦闘 |

遠征では経験値とレベルアップを通貨 **Cr（回収資材）** に置き換えました。撃破報酬と区画突破報酬で増え、改造・進化・修理に使います。開始時は20Crです。通貨はその遠征専用で、次の挑戦には持ち越しません。従来のアリーナの経験値システムはそのままです。

施設では1回購入すると次へ進みます。購入せず進むこともでき、資金不足で止まりません。改造と機体は **Q / E** または画面下のボタンで候補ページを切り替えられます。追加した種類もここに表示されます。改造の同じ効果は重複しません。

| キー | 操作 |
| --- | --- |
| クリック / 数字 / 左右＋Enter | 次の地点・購入候補を選択 |
| Q / E / ホイール | 作戦マップを横移動（長いマップの場合） |
| G | 戦闘中に作戦マップを確認。もう一度GまたはEscで復帰 |
| TAB | 現在の構成を確認 |
| Esc | 一時停止・タイトルへ戻る |
| F1 | 既存のパフォーマンス表示 |
| F2 | 既存の数値バランス調整 |
| F4 | 部屋の配置エディター |
| F5 | 遠征の進路エディター |
| F6 | 改造・敵・自機の種類エディター |

マップ確認、構成確認、エディターを開いている間は戦闘が止まります。Releaseでも編集できます。既存の `CG2_PERF_DISABLED=1` でImGui全体を無効化した場合は、F1・F2・F4〜F6の画面も無効です。通常起動では有効です。

## 3つのエディターの使い分け

### F4：部屋を作る

1. 既存区画を選ぶか「新しい区画」「区画を複製」を押します。
2. 床・通常壁・危険壁・敵／資源・自機開始・目標の道具を選び、グリッドへ配置します。
3. 目標を「配置した敵・資源をすべて破壊」「装置3個を確保」「ボス撃破」から選びます。
4. `Apply`で適用、`Save`で保存します。配置は次にその部屋へ入ったときに反映されます。

左クリックで配置、壁と消しゴムはドラッグに対応します。右クリックで敵・壁を消去できます。配置済みの敵を選ぶと種類・座標・HP上書きを編集できます。**HP上書きが0ならF6の標準HP**を使用します。自機とボスの開始位置、制圧目標の位置も変更できます。

壁への埋まり、配置同士の重なり、到達できない場所、存在しない種類などを検査し、不正な配置は適用・保存しません。外周と基本グリッド寸法は現在のエンジンに合わせて固定です。

### F5：どの順番に遊ぶかを作る

上部の経路図をクリックして地点を選びます。地点の種類、表示名、使用する部屋、戦闘の段階、突破報酬、施設価格を変更できます。接続先のチェックで進路を作り、「施設を追加」「分岐として複製」で増やせます。

接続は右の列へ進みます。行き止まりや循環、到達できない地点、部屋の参照切れは保存前に検査します。最終ボスにはF4でボス目標にした部屋を指定してください。改造地点の価格は最低価格で、実際の支払額はF6の個別価格との大きい方です。追加機体の進化価格も同様です。

**進路の変更は次の遠征から反映**します。現在の進路・残高は変わりません。Escでタイトルへ戻り、新しい遠征を始めると適用内容を試せます。

### F6：種類を増やす

「新規作成」「選択を複製」で独立したIDを持つ種類を増やせます。

- 強化：名前・説明・価格・レア度と、12種類の既存効果から最大4つの組み合わせ。
- 敵：行動型・HP・接触／射撃ダメージ・移動速度／攻撃間隔倍率・撃破通貨・ネオン色。追加したIDはF4の配置パレットへ反映。
- 自機・進化：基本型・砲門数・砲門ごとの弾数・扇の角度・威力／間隔／弾速・支援ドローン・交互射撃・反射・貫通・形状・色・価格。追加した機体は進化地点へ反映。

追加内容は実際の戦闘に使われます。すでに出現済みの敵や装備済みの機体は、その場で置き換えません。敵は次の出現、機体は次の選択で反映されます。完全に新しいAIの行動や新しい効果そのものは、引き続きコードの追加が必要です。

## 保存と現在の収録内容

`Apply`はアプリを開いている間の適用です。次の遠征にも保持します。次回起動にも残したい場合は `Save` を押してください。`Reload`は最後に保存したファイルを読み直します。保存時に問題があれば、それまでのデータを保持します。

| データ | 保存先（project以下） |
| --- | --- |
| 部屋6種類 | `resources/maps/expedition_layouts.json` |
| 進路 | `resources/configs/expedition_map.json` |
| 強化14種類・敵8種類・追加機体5種類 | `resources/configs/expedition_content.json` |
| 数値バランス | `resources/configs/tankExpeditionBalance.json` |

初期の進路は10列・5戦闘、32通りの分岐組み合わせです。基本進化6種類も残しています。危険回廊には高速狙撃兵、防衛装置区画には重装突進兵を配置しています。

今回は**編集可能な固定マップ**を土台にしました。毎回のランダム生成、イベントの文章分岐、途中セーブはまだ追加していません。まず部屋・施設・種類を直接増やして、アクションと進路選択の相性を試せる構成です。

## 参考にした設計

Mega Critは、Slay the Spire 2の地図について、地点の区別とクリックのしやすさのためにアイコンを大きくし、色を付ける変更を説明しています。今回はこの考え方を、種類別の色・文字、完了マーク、選択可能な地点の表示へ取り入れました。[公式開発記事](https://www.megacrit.com/news/2024-11-07-neowsletter-issue-4/)

Nova Driftは、アーケードアクションにモジュールの組み合わせと短い周回での試行錯誤を組み合わせています。戦車アクションを維持しながら構成の違いを作る参考として適しています。[公式サイト](https://www.novadrift.io/)

Roboquestの公式説明も、高速アクションとローグライトを組み合わせたゲームを示しています。これらから、マップで戦略を選び、区画内ではリアルタイムに動く今回の構成に致命的な相性の悪さはないと判断しました。ただし、個々の戦闘の面白さや難易度は別途プレイ検証が必要です。[公式ストア](https://store.steampowered.com/app/692890/Roboquest/)

参考画像からは進路の読みやすさを参考にしています。画像や他作品のキャラクター・背景素材はゲームへ取り込んでいません。

## 検証

`test_tank_expedition_map.ps1`、`test_tank_expedition_rooms.ps1`、`test_tank_expedition_content.ps1`で、状態遷移、全経路、支払い、重複報酬防止、配置、種類参照、不正JSON、保存・再読込を検証できます。既存の戦闘・弾・衝突・進化・チュートリアルの回帰テストも実行しています。

`test_tank_expedition_map_runtime.ps1`は実際のRelease実行ファイルで、マップ開始から購入・修理・追加機体への進化・装置確保・ボス突破を通します。結果と画面は `project/generated/expedition_map` に出力されます。これは進行の検証のため敵撃破を自動化したもので、難易度の適正を証明するテストではありません。

手動ではF4の配置追加と保存→実際の戦闘への反映、F5の設定保存と現在残高の保持、F6の複合改造の追加・保存・再読込、Gのマップ表示中の戦闘停止を確認しました。確認用の変更は元の既定データへ戻しています。
