# 射撃・体当たり・近接ビルドの調査と実装方針

調査日: 2026-09-26。下記の「確認できた内容」は開発元の説明、「今回の採用」は本作向けの判断。参照作品と同じ操作感や、全ビルドのバランス完成を意味しない。

## 一次資料で確認できた内容

- **SLAM TANK**: 開発元のSteam説明では、砲塔を回して砲身を振る攻撃、体当たり、ドリフト・攻撃・固有能力の連携、異なる3種類の戦車を紹介している。発売時期は未定で、実際に遊んで評価したものではない。[公式Steamページ](https://store.steampowered.com/app/5186030/SLAM_TANK/?l=swedish)
- **Nova Drift / Vorpal Update**: Swordsは敵と敵弾を切り、機体の衝突ダメージや移動速度を剣のダメージに結び付けられる。Hullbreakerとの組み合わせも紹介されている。近接武器が既存の成長要素とつながる例として参考になる。[開発元の更新記事](https://blog.novadrift.io/nova-drift-vorpal-update/)
- **Hyper Light Drifter**: 開発者Alex Prestonは、操作・映像・音による手応え、敵のノックバックやフラッシュ、役割の異なる敵を重視すると説明している。[開発者によるPlayStation Blog記事](https://blog.playstation.com/2014/03/14/creating-the-world-of-hyper-light-drifter-on-ps4-and-ps-vita/)

## 今回の採用

移動から体当たり、近接連撃へつながる操作を用意し、射撃とは異なる間合いを選べるようにする。SLAM TANKの空中技やスコア構造、Nova Driftの剣の増殖・敵弾切断は今回の実装対象に含めない。

| 改造 | 本作での役割 |
| --- | --- |
| ネオンブレード | 射撃操作を3段の近接連撃へ変更する入口 |
| 刃先延長 | ブレード取得後に射程+30%、近接ダメージ+20% |
| 衝突増幅 | 体当たりの威力と押し出し、近接の押し出しを強化 |
| ジャスト回避 | 敵弾へのダッシュ開始直後の回避判定を解放 |

体へのダッシュは初期状態から体当たりとして使える。ジャスト回避は別の改造で、最初から敵弾に対して発動しない。蓄電池はジャスト回避取得後に提示し、取得時点で効果を使えない改造を減らす。刃先延長とブレード、衝突増幅とブレードをまとめたキットも用意する。

威力・連射の基礎改造は近接にも関係させ、近接専用改造だけを集める一本道にしない。通常射撃は**1砲塔につき1発**とし、複数の砲塔を持つ機体は各砲塔から1発ずつ発射する。拡散・分裂改造は提示とF6編集から外す。ダッシュ放電も放射状の弾を追加する方式から衝撃波へ変える。

見せ方は、短い振り始め、刃の軌跡、当たった方向への押し出し、3段目の強い反応を中心にする。原神・崩壊：スターレイル・鳴潮はユーザーが挙げた視覚表現の参照として扱い、本作へのゲーム構造の移植や、各作品の技術的な再現を約束するものではない。

## 導入と編集データ

導入2ルートは同じランのシードから、威力・連射・移動・装甲・貫通の5候補を使って同じ3枚を提示する。乱数は戦闘用の乱数状態を消費しない。導入価格はシーン側で15にし、通常の店では各改造の価格を使う。基礎値の伸びを控えめにして、導入だけで戦闘の成長が完結しないようにする。

旧データの数値IDは維持し、廃止したScatterShotの効果を読み込み時に取り除く。空になった旧改造だけを除き、敵・自機などの制作済みデータは残す。旧反射分裂キットは反射貫通キットへ移行する。F6では同時発射数を増やせず、砲塔数は引き続き編集できる。

カタログ・条件判定・導入候補・旧データ移行は自動テストで確認する。実機での攻撃の見やすさ、敵への接近難度、近接と射撃の有利不利はプレイ検証を続けて調整する。
