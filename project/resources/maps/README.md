# 短エリア試作のマップ

`expedition_*.csv` は既存 `resources/map.csv` と独立した4つの小部屋です。各CSVは45列×30行、0=空間、1=壁、2=接触ダメージのある壁です。ワールド座標は `x=列×2`、`y=(29−行)×2`。外壁はx20〜68、y14〜44です。

| ファイル | 地形 |
|---|---|
| expedition_crossfire.csv | 斜めにずらした2つの遮蔽物。中央射線と側面移動を使い分ける |
| expedition_resource_fork.csv | 中央のコアへ直進する射線と、上下から回り込む経路 |
| expedition_hazard_lane.csv | 切れ目のある2本の危険壁。中央と外周の移動を選ぶ |
| expedition_final_duel.csv | 中央を広く空け、四隅の遮蔽物で弾を切る決闘場 |

配置候補は `expedition_rooms.json` にあります。全マップでプレイヤー(26,28)、ライバル(62,30)、コア(44,30)を使用できます。射撃敵候補は(28,20)、(60,20)、(28,38)、(60,38)。各点はライバルの移動用3×3セルの空間を持ち、互いに接続しています。

`Stage::LoadRunMap(path)` はCSVを検証してから古い壁と統合衝突形状を置き換えます。ファイル不在・不正な行列数・未対応の値ではfalseを返し、現マップを維持します。読み込み後はシーン側のステージ描画キャッシュを無効にしてください。

部屋終了のコールバック内では遷移を予約するだけにします。次の更新開始時に、弾・攻撃エフェクト・ドローン等の旧部屋参照を解放し、`EnemyManager::ClearRunActors()`、マップ読込、プレイヤー再配置、`Enemy::ResetRunEncounter(...)`、部屋の敵生成を行います。マネージャのclearは既存のアクターポインタを無効にするので、衝突処理やコールバックの途中では呼ばないでください。
